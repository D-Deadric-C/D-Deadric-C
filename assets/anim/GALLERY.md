# Animation Gallery

14 candidate animations. All are self-contained SMIL SVGs (no CSS `@keyframes`,
no external assets) so they animate correctly when GitHub embeds them as `<img>`.

Tell me the numbers you want and I'll wire them into the README and delete the rest.

Base stays monochrome — these use colour deliberately, since they're the "interesting" bits.
